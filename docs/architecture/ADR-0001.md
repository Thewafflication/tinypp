# ADR-0001: Hosted C++98 and explicit defects

**Content type:** Architecture decision record

**Status:** Proposed

**Date:** 2026-10-31

## Context

C++03 corrections and later defect resolutions can change behavior. Public
drafts do not replace the final edition. Full completion includes export and
hosted libraries in the combined toolchain. Templates and the standard library
are owned by an existing separate project.

## Decision Drivers

C++98 hosted completeness; audited TinyCC/DMC reuse; bounded initial target;
reproducible WSP evidence.

## Considered Options

1. ISO C++98 hosted with explicit defect ledger.
2. Use C++03 as proxy.
3. Ship a subset as full compliance.

## Decision

Use ISO/IEC 14882:1998 as the normative target. Reconcile the public draft
with a lawfully available final edition. Record each adopted defect resolution
independently. Include export, exceptions, RTTI, deprecated facilities and all
required hosted libraries in combined-delivery completion. This compiler
project owns core semantics and external integration contracts; template and
standard-library implementation remain with the existing separate project.
Permit compiler-core releases with explicit scope before combined completion.

## Rationale

Preserves the requested edition without silently importing later semantics.

## Consequences

### Positive

Stable scope and honest claims.

### Negative

Historical reconciliation and export add significant work.

### Follow-up

REQ-0001 through REQ-0007; REQ-0021; REQ-0041. M0 defines the inventory; M6
verifies externally supplied export; M8 reviews scoped and combined claims.
