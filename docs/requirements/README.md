# Requirement index

**Content type:** Controlled index

All requirements are Proposed; all verification is planned, not executed.
The standards obligation inventory will refine these capability requirements
into clause-level obligations before acceptance. IDs are permanent.

REQ-0019–0021 and REQ-0028–0033 are externally allocated to the existing
templates and standard-library project. Their milestones specify integration
acceptance, not implementation in Tiny++. See the owner column in the
traceability table and the cross-project section in each requirement.
