# REQ-0002 — Standards obligation inventory

**Content type:** Requirement

**Status:** Proposed

**Source:** S1; S2; see [source register](../research/standards.md).

## Scope

Tiny++ hosted C++98 implementation and its controlled engineering records.
Allocation: M0. Target scope follows ADR-0003; intermediate subsets do not
establish full conformance.

## Requirement

The project shall maintain a reviewed inventory mapping every normative C++98
obligation to a project requirement and verification specification.

## Rationale

Makes standards obligation inventory an explicit, reviewable part of the C++98
product baseline instead of inheriting an unverified upstream assumption.

## Verification

**Method:** Inspection and analysis

**References:** [TC-0002](../testing/cases/TC-0002.tex).

Compare the licensed final edition clause by clause, including annex normative
status, with the inventory; every obligation needs an anchor, requirement,
oracle and disposition. Missing final text or unresolved differences yields
Blocked.

## Relationships

- **Derived from:** Source above and stakeholder C++98 compiler objective.
- **Depends on:** [REQ-0001](REQ-0001.md); detailed standards allocation in REQ-0002.
- **Conflicts with:** No known conflict; deviations require impact review.

## Tailoring

None for a full conformance claim. Intermediate milestones may implement a
published subset without claiming that this requirement is verified.

Planned; no Tiny++ implementation or execution evidence exists in this change.
