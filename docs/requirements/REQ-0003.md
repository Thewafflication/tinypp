# REQ-0003 — Defect resolution control

**Content type:** Requirement

**Status:** Proposed

**Source:** S3; S4; see [source register](../research/standards.md).

## Scope

Tiny++ hosted C++98 implementation and its controlled engineering records.
Allocation: M0. Target scope follows ADR-0003; intermediate subsets do not
establish full conformance.

## Requirement

The project shall record each adopted core or library defect resolution with
its issue number, revision, affected edition, behavioral impact and regression
test.

## Rationale

Makes defect resolution control an explicit, reviewable part of the C++98
product baseline instead of inheriting an unverified upstream assumption.

## Verification

**Method:** Inspection and analysis

**References:** [TC-0003](../testing/cases/TC-0003.tex).

Inspect adopted, rejected and pending ledger entries against pinned committee
snapshots; verify there is no automatic adoption of later language wording or
silent C++03 change.

None for a full conformance claim. Intermediate milestones may implement a
