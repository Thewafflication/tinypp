# REQ-0008 — Translation and preprocessing

**Content type:** Requirement

**Status:** Proposed

**Source:** S2 [lex.phases]; [cpp]; see [source register](../research/standards.md).

## Scope

Tiny++ hosted C++98 implementation and its controlled engineering records.
Allocation: M2. Target scope follows ADR-0003; intermediate subsets do not
establish full conformance.

## Requirement

The compiler shall implement the C++98 translation phases and preprocessing
rules within its documented resource limits.

## Rationale

Makes translation and preprocessing an explicit, reviewable part of the C++98
product baseline instead of inheriting an unverified upstream assumption.

## Verification

**Method:** Test and review

**References:** [TC-0008](../testing/cases/TC-0008.tex).

Exercise backslash-newline splicing, comments, trigraphs, digraphs,
conditional inclusion, macro rescanning, stringizing, token pasting, includes
and #line in separate fixtures; compare tokens and source locations with
reviewed oracles.

## Relationships

- **Derived from:** Source above and stakeholder C++98 compiler objective.
- **Depends on:** [REQ-0001](REQ-0001.md); detailed standards allocation in REQ-0002.
- **Conflicts with:** No known conflict; deviations require impact review.

## Tailoring

None for a full conformance claim. Intermediate milestones may implement a
published subset without claiming that this requirement is verified.

## Implementation Record

Partial character translation, trigraphs, line splicing, source mapping and
comment/token handling are implemented. See the
[compiler foundation](../process/compiler-foundation.md). Macro/include and
other preprocessing obligations remain open; the complete TC is unverified.
