# REQ-0010 — Types and declarations

**Content type:** Requirement

**Status:** Proposed

**Source:** S2 [basic.types]; [dcl.dcl]; [dcl.decl]; see [source register](../research/standards.md).

## Scope

Tiny++ hosted C++98 implementation and its controlled engineering records.
Allocation: M3. Target scope follows ADR-0003; intermediate subsets do not
establish full conformance.

## Requirement

The semantic analyzer shall enforce C++98 type and declaration rules.

## Rationale

Makes types and declarations an explicit, reviewable part of the C++98 product
baseline instead of inheriting an unverified upstream assumption.

## Verification

**Method:** Test and review

**References:** [TC-0010](../testing/cases/TC-0010.tex).

Test cv qualification, typedefs, enums, references, arrays, function pointers,
pointer-to-member types, declarator precedence and incomplete types using
positive and one-rule negative variants; check sizeof and overload-based type
oracles.

## Relationships

- **Derived from:** Source above and stakeholder C++98 compiler objective.
- **Depends on:** [REQ-0001](REQ-0001.md); detailed standards allocation in REQ-0002.
- **Conflicts with:** No known conflict; deviations require impact review.

## Tailoring

None for a full conformance claim. Intermediate milestones may implement a
published subset without claiming that this requirement is verified.

## Implementation Record

Partial scalar type and reference implementation is recorded in the
[compiler foundation](../process/compiler-foundation.md). Full declaration
and type-system verification remains open.
