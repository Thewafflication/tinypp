# REQ-0017 — Inheritance and dispatch

**Content type:** Requirement

**Status:** Proposed

**Source:** S2 [class.derived]; [class.virtual]; see [source register](../research/standards.md).

## Scope

Tiny++ hosted C++98 implementation and its controlled engineering records.
Allocation: M4. Target scope follows ADR-0003; intermediate subsets do not
establish full conformance.

## Requirement

The compiler shall implement C++98 inheritance and virtual dispatch semantics.

## Rationale

Makes inheritance and dispatch an explicit, reviewable part of the C++98
product baseline instead of inheriting an unverified upstream assumption.

## Verification

**Method:** Test and review

**References:** [TC-0017](../testing/cases/TC-0017.tex).

Run single, multiple and virtual diamond inheritance, virtual destructors,
covariant returns and member pointers with nonzero this adjustments; assert
dispatch, base identity and destruction traces across translation units.

## Relationships

- **Derived from:** Source above and stakeholder C++98 compiler objective.
- **Depends on:** [REQ-0001](REQ-0001.md); detailed standards allocation in REQ-0002.
- **Conflicts with:** No known conflict; deviations require impact review.

## Tailoring

None for a full conformance claim. Intermediate milestones may implement a
published subset without claiming that this requirement is verified.
