# REQ-0020 — Dependent name lookup

**Content type:** Requirement

**Status:** Proposed

**Source:** S2 [temp.res]; [temp.dep]; see [source register](../research/standards.md).

## Cross-project allocation

The existing separate templates and standard-library project owns this
implementation. Tiny++ owns the compiler integration contract and local
acceptance checks. This is an external dependency, not a compiler-project
implementation gate. See [ownership and DMC candidates](../research/dmc-reuse.md).
The producer repository and delivery revision remain to be identified.

## Scope

Tiny++ hosted C++98 implementation and its controlled engineering records.
Allocation: M5. Target scope follows ADR-0003; intermediate subsets do not
establish full conformance.

## Requirement

The semantic analyzer shall resolve dependent template names using C++98
definition and instantiation contexts.

## Rationale

Makes dependent name lookup an explicit, reviewable part of the C++98 product
baseline instead of inheriting an unverified upstream assumption.

## Verification

**Method:** Test and review

**References:** [TC-0020](../testing/cases/TC-0020.tex).

Use a nondependent call with a later overload, dependent ADL call, dependent
base, typename and template disambiguators plus substitution failures;
reviewed overload results distinguish early binding from delayed lookup.
