# REQ-0021 — Exported templates

**Content type:** Requirement

**Status:** Proposed

**Source:** S2 [temp.export]; [temp]; see [source register](../research/standards.md).

## Cross-project allocation

The existing separate templates and standard-library project owns this
implementation. Tiny++ owns the compiler integration contract and local
acceptance checks. This is an external dependency, not a compiler-project
implementation gate. See [ownership and DMC candidates](../research/dmc-reuse.md).
The producer repository and delivery revision remain to be identified.

## Scope

Tiny++ hosted C++98 implementation and its controlled engineering records.
Allocation: M6. Target scope follows ADR-0003; intermediate subsets do not
establish full conformance.

## Requirement

The implementation shall support C++98 exported templates whose definitions
are unavailable in the importing translation unit.

## Rationale

Makes exported templates an explicit, reviewable part of the C++98 product
baseline instead of inheriting an unverified upstream assumption.

## Verification

**Method:** Test and review

**References:** [TC-0021](../testing/cases/TC-0021.tex).

Compile an exported function-template definition in one unit and a
declaration-only consumer in another with no definition header or unity build;
link/run int and double instantiations, then change the definition and confirm
repository invalidation.
