# REQ-0022 — Exception propagation

**Content type:** Requirement

**Status:** Proposed

**Source:** S2 [except]; see [source register](../research/standards.md).

## Scope

Tiny++ hosted C++98 implementation and its controlled engineering records.
Allocation: M4. Target scope follows ADR-0003; intermediate subsets do not
establish full conformance.

## Requirement

The implementation shall implement C++98 exception matching and stack
unwinding.

## Rationale

Makes exception propagation an explicit, reviewable part of the C++98 product
baseline instead of inheriting an unverified upstream assumption.

## Verification

**Method:** Test and review

**References:** [TC-0022](../testing/cases/TC-0022.tex).

Throw across function and translation-unit boundaries, catch base/reference
and catch-all, rethrow and fail a constructor; assert handler selection,
object identity and reverse cleanup order.

## Relationships

- **Derived from:** Source above and stakeholder C++98 compiler objective.
- **Depends on:** [REQ-0001](REQ-0001.md); detailed standards allocation in REQ-0002.
- **Conflicts with:** No known conflict; deviations require impact review.

## Tailoring

None for a full conformance claim. Intermediate milestones may implement a
published subset without claiming that this requirement is verified.

## Implementation Record

Planned; no Tiny++ implementation or execution evidence exists in this change.
