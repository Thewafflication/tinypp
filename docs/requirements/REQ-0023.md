# REQ-0023 — Exception specifications

**Content type:** Requirement

**Status:** Proposed

**Source:** S2 [except.spec]; [except.unexpected]; see [source register](../research/standards.md).

## Scope

Tiny++ hosted C++98 implementation and its controlled engineering records.
Allocation: M4. Target scope follows ADR-0003; intermediate subsets do not
establish full conformance.

## Requirement

The implementation shall implement C++98 dynamic exception specifications and
termination handlers.

## Rationale

Makes exception specifications an explicit, reviewable part of the C++98
product baseline instead of inheriting an unverified upstream assumption.

## Verification

**Method:** Test and review

**References:** [TC-0023](../testing/cases/TC-0023.tex).

In isolated child processes exercise allowed throw, throw() violation,
unexpected handler and bad_exception substitution where specified; verify
handler markers and termination policy without assuming an OS exit code.

## Relationships

- **Derived from:** Source above and stakeholder C++98 compiler objective.
- **Depends on:** [REQ-0001](REQ-0001.md); detailed standards allocation in REQ-0002.
- **Conflicts with:** No known conflict; deviations require impact review.

## Tailoring

None for a full conformance claim. Intermediate milestones may implement a
published subset without claiming that this requirement is verified.

Planned; no Tiny++ implementation or execution evidence exists in this change.
