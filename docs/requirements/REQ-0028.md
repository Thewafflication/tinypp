# REQ-0028 — Language support library

**Content type:** Requirement

**Status:** Proposed

**Source:** S2 clause 18; see [source register](../research/standards.md).

## Cross-project allocation

The existing separate templates and standard-library project owns this
implementation. Tiny++ owns the compiler integration contract and local
acceptance checks. This is an external dependency, not a compiler-project
implementation gate. See [ownership and DMC candidates](../research/dmc-reuse.md).
The producer repository and delivery revision remain to be identified.

## Scope

Tiny++ hosted C++98 implementation and its controlled engineering records.
Allocation: M7. Target scope follows ADR-0003; intermediate subsets do not
establish full conformance.

## Requirement

The hosted implementation shall provide C++98 language-support library
facilities.

## Rationale

Makes language support library an explicit, reviewable part of the C++98
product baseline instead of inheriting an unverified upstream assumption.

## Verification

**Method:** Test and review

**References:** [TC-0028](../testing/cases/TC-0028.tex).

Instantiate facilities from cstddef, limits, climits, cfloat, cstdlib, new,
typeinfo, exception and cstdarg; check numeric limits against target probes
and handler/allocation behavior using per-entity reviewed cases.

## Relationships

- **Derived from:** Source above and stakeholder C++98 compiler objective.
- **Depends on:** [REQ-0001](REQ-0001.md); detailed standards allocation in REQ-0002.
- **Conflicts with:** No known conflict; deviations require impact review.

## Tailoring

None for a full conformance claim. Intermediate milestones may implement a
published subset without claiming that this requirement is verified.

## Implementation Record

Externally allocated; no delivery or integration evidence has been recorded.
