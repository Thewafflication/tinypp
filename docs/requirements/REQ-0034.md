# REQ-0034 — Implementation choices and limits

**Content type:** Requirement

**Status:** Proposed

**Source:** S2 [intro.compliance]; annex B; see [source register](../research/standards.md).

## Scope

Tiny++ hosted C++98 implementation and its controlled engineering records.
Allocation: M2. Target scope follows ADR-0003; intermediate subsets do not
establish full conformance.

## Requirement

The project shall document each C++98 implementation-defined behavior and
resource limit for every supported target.

## Rationale

Makes implementation choices and limits an explicit, reviewable part of the
C++98 product baseline instead of inheriting an unverified upstream
assumption.

## Verification

**Method:** Test and review

**References:** [TC-0034](../testing/cases/TC-0034.tex).

Review the edition obligation inventory for every documentation obligation;
probe widths, signed char, wchar_t, encodings, floating behavior and declared
translation limits at/below/above boundaries. Above-limit behavior follows
published policy and is not assumed ISO-mandated rejection.

## Relationships

- **Derived from:** Source above and stakeholder C++98 compiler objective.
- **Depends on:** [REQ-0001](REQ-0001.md); detailed standards allocation in REQ-0002.
- **Conflicts with:** No known conflict; deviations require impact review.

## Tailoring

None for a full conformance claim. Intermediate milestones may implement a
published subset without claiming that this requirement is verified.
