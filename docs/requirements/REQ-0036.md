# REQ-0036 — Distribution obligations

**Content type:** Requirement

**Status:** Proposed

**Source:** Dependency provenance; ADR-0002; see [source register](../research/standards.md).

## Scope

Tiny++ hosted C++98 implementation and its controlled engineering records.
Allocation: M8. Target scope follows ADR-0003; intermediate subsets do not
establish full conformance.

## Requirement

The release process shall satisfy the recorded license obligations for
distributed compiler and runtime artifacts.

## Rationale

Makes distribution obligations an explicit, reviewable part of the C++98
product baseline instead of inheriting an unverified upstream assumption.

## Verification

**Method:** Inspection and analysis

**References:** [TC-0036](../testing/cases/TC-0036.tex).

Build a package inventory and compare source offers/source availability,
notices and linkage conditions with the reviewed per-file obligations; reject
unidentified files or unresolved obligations; retain the review without
claiming a new project license.

## Relationships

- **Derived from:** Source above and stakeholder C++98 compiler objective.
- **Depends on:** [REQ-0001](REQ-0001.md); detailed standards allocation in REQ-0002.
- **Conflicts with:** No known conflict; deviations require impact review.

## Tailoring

None for a full conformance claim. Intermediate milestones may implement a
published subset without claiming that this requirement is verified.
