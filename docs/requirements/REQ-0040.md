# REQ-0040 — Traceability gate

**Content type:** Requirement

**Status:** Proposed

**Source:** WSP-REQM-0005; WSP-TEST-0011; see [source register](../research/standards.md).

## Scope

Tiny++ hosted C++98 implementation and its controlled engineering records.
Allocation: M1. Target scope follows ADR-0003; intermediate subsets do not
establish full conformance.

## Requirement

The project CI shall reject inconsistent requirement-to-test relationships.

## Rationale

Makes traceability gate an explicit, reviewable part of the C++98 product
baseline instead of inheriting an unverified upstream assumption.

## Verification

**Method:** Test and review

**References:** [TC-0040](../testing/cases/TC-0040.tex).

Run the artifact checker on a valid fixture and isolated mutations with
missing requirement, duplicate case ID, removed back-reference and absent
release result; valid fixture passes and every mutation fails with an
identifying diagnostic.

## Relationships

- **Derived from:** Source above and stakeholder C++98 compiler objective.
- **Depends on:** [REQ-0001](REQ-0001.md); detailed standards allocation in REQ-0002.
- **Conflicts with:** No known conflict; deviations require impact review.

## Tailoring

None for a full conformance claim. Intermediate milestones may implement a
published subset without claiming that this requirement is verified.
