# REQ-0042 — User documentation

**Content type:** Requirement

**Status:** Proposed

**Source:** WSP information-for-users profile; see [source register](../research/standards.md).

## Scope

Tiny++ hosted C++98 implementation and its controlled engineering records.
Allocation: M8. Target scope follows ADR-0003; intermediate subsets do not
establish full conformance.

## Requirement

The release shall provide a user reference covering invocation, supported
targets, language modes, implementation choices, limits and known deviations.

## Rationale

Makes user documentation an explicit, reviewable part of the C++98 product
baseline instead of inheriting an unverified upstream assumption.

## Verification

**Method:** Inspection and analysis

**References:** [TC-0042](../testing/cases/TC-0042.tex).

Follow clean-machine install, compile/link and diagnostic examples; compare
documented defaults and limitations against release manifest,
implementation-choice register and test evidence.

## Relationships

- **Derived from:** Source above and stakeholder C++98 compiler objective.
- **Depends on:** [REQ-0001](REQ-0001.md); detailed standards allocation in REQ-0002.
- **Conflicts with:** No known conflict; deviations require impact review.

## Tailoring

None for a full conformance claim. Intermediate milestones may implement a
published subset without claiming that this requirement is verified.

## Implementation Record

Planned; no Tiny++ implementation or execution evidence exists in this change.
