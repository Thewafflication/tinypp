# REQ-0043 — Release matrix completeness

**Content type:** Requirement

**Status:** Proposed

**Source:** WSP-TEST-0013; WSP-TEST-0017; see [source register](../research/standards.md).

## Scope

Tiny++ hosted C++98 implementation and its controlled engineering records.
Allocation: M8. Target scope follows ADR-0003; intermediate subsets do not
establish full conformance.

## Requirement

The release process shall execute all required verification cases on every
supported release-matrix entry.

## Rationale

Makes release matrix completeness an explicit, reviewable part of the C++98
product baseline instead of inheriting an unverified upstream assumption.

## Verification

**Method:** Inspection and analysis

**References:** [TC-0043](../testing/cases/TC-0043.tex).

Inspect Debug/Release records for each target, including native execution
architecture; missing or cross-build-only runtime evidence fails. Mark
proposed ports outside the matrix rather than reporting them passed.

## Relationships

- **Derived from:** Source above and stakeholder C++98 compiler objective.
- **Depends on:** [REQ-0001](REQ-0001.md); detailed standards allocation in REQ-0002.
- **Conflicts with:** No known conflict; deviations require impact review.

## Tailoring

None for a full conformance claim. Intermediate milestones may implement a
published subset without claiming that this requirement is verified.

## Implementation Record

Planned; no Tiny++ implementation or execution evidence exists in this change.
